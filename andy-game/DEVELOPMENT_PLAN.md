# Andy林浚之100层房子 - 分布式开发计划

## 项目概述

为6岁以下儿童开发的睡前故事互动游戏。主角Andy进入云端100层房子，每次游玩可按3次电梯随机到达楼层，每层有独立小游戏。

## 技术架构

```
技术栈：React 18 + Vite + TypeScript
状态：Zustand + localStorage
动画：framer-motion
音效：Web Audio API (MVP) → howler.js (正式)
渲染：SVG(棋盘) + DOM(问答) + Canvas(复杂棋盘)
部署：静态托管，无需后端
```

**楼层注册机制**（核心架构）：
```typescript
// src/floors/_registry.ts
const floorModules = {
  1: () => import('./f001-gomoku'),     // 每层lazy loading
  2: () => import('./f002-guess-number'),
  // ... 新增一行即可添加楼层
};
```

```

  ├── F005 英语词汇 ── 独立可开发
  ├── F006 拼音 ── 独立可开发
  └── F008 成语 ── 独立可开发

Phase 3（棋牌/幻想）── 依赖 Phase 1
  ├── F004 钻石棋 ── 独立可开发
  ├── F007 斗兽棋 ── 独立可开发
  └── F009 简化斗地主 ── 独立可开发

```

**关键特征**：每个楼层游戏完全独立，可并行开发，互不阻塞。

## 当前可用功能验证

1. 打开 http://localhost:5173
2. 选择Andy → 进入云端大厅
3. 按3次电梯，每次随机到达1楼（目前仅实现1楼）
4. 五子棋：下棋对战AI / 点击"认输"或"认赢"
5. 刷新页面 → 进度保持，电梯次数重置为3
